# 💰 Finance Tracker — Personal Budgeting App

A personal finance management system built for Generation Z users.
Developed as a Final Year Project using Python and SQLite.

---

## 📌 About

This app helps users manage their personal finances through:
- 💳 Account balance tracking (up to 5 accounts)
- 📊 Budget creation and monitoring with real-time alerts
- 💸 Transaction logging with categories, tags, notes and references
- 🔁 Recurring transactions that auto-fire on login
- 🔄 Subscription tracking
- 🎯 Wishlist / savings goal tracker
- 📈 Dashboard with income vs expense charts
- 🏅 Badge and streak system for engagement
- ⚙️ Multi-currency support (20+ currencies)

## 🚀 How To Run

### Step 1 — Clone the repository
```bash
git clone https://github.com/yourusername/finance-tracker.git
cd finance-tracker
```

### Step 2 — Install required libraries
```bash
pip install -r requirements.txt
```

### Step 3 — Run the app
```bash
python capstone_project_code.py
```

The database file `budgeting_app.db` will be created automatically
in the same folder on first run. You do not need to create it manually.
